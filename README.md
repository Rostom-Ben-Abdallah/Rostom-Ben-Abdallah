# Rostom Ben Abdallah

**Industrial Computer Engineering | Computer Vision | Visual AI | Robotics Perception**

I am an Industrial Computer Engineering student at **ENET'Com** and a **Mitacs research intern at Université de Moncton**, working on applied computer vision for automated behavioural monitoring from video.

My interests include **object detection, multi-object tracking, segmentation, re-identification, action recognition, video understanding, multimodal perception, and real-time/edge AI**.

## Current research

### AI-based visual monitoring and behaviour understanding

My current research work focuses on building an end-to-end computer vision pipeline for behavioural analysis from multi-camera video. My contributions include:

- object and body detection
- multi-object tracking and temporal identity stabilization
- individual identification using visual cues
- segmentation and annotation-quality workflows
- large-scale video dataset preparation and evaluation
- video-based action / behaviour recognition
- model benchmarking on HPC infrastructure
- research tooling for visual review and structured result export

**Research technologies:** Python, OpenCV, PyTorch, YOLO, RF-DETR, GroundingDINO, SAM, vision-language models, tracking/Re-ID methods, Linux, CUDA, Slurm/HPC.

## Selected applied computer vision experience

### Real-time tracking and counting
Built vision pipelines combining detection/segmentation, tracking, ROI logic, identity filtering, event counting, operator interfaces, and structured logging.

### Industrial visual quality control
Developed real-time inspection pipelines using deep-learning detection together with classical computer vision for position, appearance, readability, and pass/fail decision logic, including integration with industrial control systems.

### Multi-camera recognition and access analytics
Worked on multi-camera visual systems combining person detection, tracking, re-identification, face embeddings, and event logic for IN/OUT analysis.

### Edge AI and embedded vision
Deployed and optimized vision pipelines with ONNX, Raspberry Pi, CUDA-capable systems, and real-time camera streams.
